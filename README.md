# Telegram-бот для учёта работы лабораторного оборудования
## Расширенная версия

### Что нового
- Ввод номера образца / заявки / комментария при старте сессии
- Отчёты с фильтрами: этот месяц, этот год, прошлый месяц, всё время
- Автоматические напоминания, если сессия длится дольше 10 часов
- Улучшенный экспорт CSV (с колонкой «Номер/заметка»)

### Как запустить

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot).
3. В файле `lab_equipment_bot.py` замените:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `EQUIPMENT_LIST` (ваши 7 приборов)
4. Установите зависимости и запустите:
   ```bash
   pip install -r requirements.txt
   python lab_equipment_bot.py
   ```

### Доступ
- Только по приглашению. Админ создаёт одноразовую ссылку через кнопку **🔗 Пригласить**.
- Несколько админов: первый задаётся через `ADMIN_ID`. В меню **👥 Пользователи** можно сделать любого пользователя админом или отозвать доступ.
- Обычные пользователи видят только свои сессии.

### Приветственная картинка
Положите файл `welcome.jpg` в ту же папку, где лежит `lab_equipment_bot.py`.  
При команде `/start` бот отправит эту картинку с приветствием.  
Если файла нет — отправит только текст.

### Как пользоваться

1. **▶️ Начать работу** → оборудование → тип (Наука/Услуга) → введите номер образца или «-» чтобы пропустить.
2. **⏹ Закончить работу** → выбираете сессию → бот считает часы.
3. Для администратора:
   - **📊 Отчёт** → выбор периода
   - **📥 Экспорт CSV**

### Напоминания
Бот сам присылает сообщение сотруднику, если сессия висит дольше 10 часов (настраивается в `REMINDER_HOURS`).

### Google Таблицы
Прямая выгрузка в Google Sheets требует сервисного аккаунта Google Cloud и файла credentials.json.  
Если нужно — могу добавить эту функцию отдельно (напишите).  
Пока самый простой путь: экспортировать CSV и загружать в Google Таблицу вручную (или через Apps Script).

## Деплой на Railway (24/7)

Полная инструкция в файле `RAILWAY.md`.

Кратко:
1. Залейте код на GitHub.
2. На [railway.app](https://railway.app) → Deploy from GitHub.
3. Добавьте переменные: `BOT_TOKEN` и `ADMIN_ID`.
4. (Рекомендуется) Подключите Volume в `/data`, чтобы база не сбрасывалась.

После деплоя бот работает круглосуточно.

Бот готов к работе. Если нужно что-то ещё доработать — скажите.
